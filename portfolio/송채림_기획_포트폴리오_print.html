문제 발견

"내가 팔고 싶다면, 다른 창작자도 팔고 싶지 않을까?"

코바늘 제품을 만들어 판매하고 싶었지만 처음부터 매장을 임대하기엔 부담스럽고, 짧게 제품을 판매하며 고객 반응을 확인할 공간은 찾기 어려웠습니다.

여기서 질문을 하나 던졌습니다.

"이게 나만의 문제일까?"

코바늘뿐 아니라 키링과 엽서, 액세서리 등 직접 만든 제품을 판매하는 청년 창작자도 같은 문제를 겪을 것이라는 가설을 세우고, 청년 창작자와 지역 유휴공간을 연결하는 POP-IN을 기획했습니다.

만든 과정
01 문제를 서비스로 설계 개인 경험 → 타깃 가설 → 경쟁 서비스 분석 → PRD → 핵심 기능 → User Flow
02 AI로 직접 개발 ChatGPT로 요구사항을 구조화하고 Claude Code로 웹 MVP를 구현했습니다. 결과물을 직접 테스트하며 픽셀·비율·정렬 단위로 수정 명령을 내려 UI를 반복 개선했습니다.
03 아이디어에서 끝내지 않고 검증까지 Google Forms로 수요자·공급자별 설문을 설계해 실제 시장 수요를 확인할 수 있는 검증 구조까지 만들었습니다.
AI에게 전달하는 법

"더 예쁘게"는 AI가 실행할 수 없습니다. 원하는 결과가 나올 때까지 기준을 숫자로 바꿔서 다시 지시했습니다.

더 예쁘게 → 카드 간격 24px 썸네일 4:3 고정 CTA를 카드 하단 정렬 가격을 제목보다 크게
결과

공간 탐색→ 상세 확인→ 팝업 신청→ 공급자 승인

기획서만 만든 것이 아니라 아래 전 과정을 직접 수행했습니다.

문제 발견→ 서비스 기획→ UX/UI→ AI 개발→ MVP→ 수요 검증 설계
배운 점

AI를 잘 쓰는 것은 좋은 답을 받는 것이 아니라, 원하는 결과가 나올 때까지 정확하게 지시하고 판단하는 능력이었습니다.

추상적인 아이디어를 개발 가능한 요구사항으로 바꾸고, AI와 반복적으로 구현하고 수정하면서 기획자가 AI로 아이디어를 실제 제품으로 만드는 방법을 경험했습니다.

구분Personal Project

역할콘텐츠 기획 · 제작 · AI 활용

ToolsChatGPT · Claude Code · CapCut

POP-IN의 출발점. 이 제품을 팔 공간을 찾다가 Project 01이 나왔습니다.

Problem

손으로 만든 과정은 머릿속과 사진에만 남습니다. 다른 사람이 따라 하려면 재료와 코 수, 단별 순서가 정해진 형식으로 정리돼 있어야 합니다.

What I Did
  • 제작 과정 및 도안 정보 구조화 재료와 도구, 단별 과정, 코 수와 뜨개 방식, 완성 크기, 기호, 주의사항으로 항목을 나눴습니다.
  • 웹 기반 디지털 도안 제작
  • 영상 촬영 및 단계별 콘텐츠 구성
  • AI를 활용한 자막·콘텐츠 제작 Workflow 실험
Result
디지털 코바늘 도안 영상 콘텐츠

AI가 콘텐츠를 대신 만드는 게 아니라, 반복 작업을 줄여서 제작자가 구조와 품질 판단에 집중하게 하는 쪽으로 썼습니다.
